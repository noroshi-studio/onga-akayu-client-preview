# 遠賀川温泉 おんがの赤湯 — Phase 1 静的プレビュー

デザイン確認用の静的HTML/CSS/JavaScript版です。WordPressテーマではありません。

## 確認方法

### ファイルを直接開く

`index.html` をブラウザへドラッグ＆ドロップするか、ダブルクリックしてください。主要コンテンツとローカルSVGは `file://` でも表示できます。Google Fontsだけはインターネット接続時に読み込まれ、失敗時は日本語システムフォントへ切り替わります。

### ローカルサーバーを使う（推奨）

ターミナルで `static-preview` に移動し、次のいずれかを実行します。

```sh
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080/` を開いてください。

## オープニング演出

- 同一タブのセッション中、初回アクセス時だけ約5.4秒表示します。右上の「SKIP」または `Escape` キーで約0.48秒かけて終了します。
- 開発・確認時はURLの末尾に `?intro=1` を付けると、同一セッション中でも再表示できます。
- `prefers-reduced-motion: reduce` では移動・拡大を行わず、約5.4秒の穏やかなフェードで表示します。JavaScript無効時はオープニングを表示しません。
- 背景とロゴはプレゼン用イメージです。実在施設の正式写真・正式ロゴとして公開する前に、施設側の確認と使用許諾が必要です。

### 本番画像への差し替え

| 用途 | 差し替えるファイル | 推奨仕様 |
| --- | --- | --- |
| 背景 | `assets/images/opening/onga-akayu-opening-bg.png` | 1920×1280px以上、横3:2前後、PNG・WebP・JPEG。主題は中央付近に配置 |
| ロゴ | `assets/images/opening/onga-akayu-logo.jpg` | 1000×1000px程度の正方形、可能なら余白を整えた透過PNG |

同じファイル名で置き換えればHTML・CSS・JavaScriptの変更は不要です。拡張子を変える場合だけ、`index.html` 内のオープニング画像の `src` を変更してください。背景をPC用とスマートフォン用に分ける場合は、同じ箇所の `picture` 内へ `source media="(max-width: 600px)"` を追加できます。画像寸法を変えた場合は、CLS防止のため `width` と `height` も実ファイルに合わせて更新してください。コピーは `index.html` の `.onga-opening__copy` を編集し、不要なら要素ごと削除できます。

## 画像差し替え一覧

現在の画像はすべて本案件向けに作成したオリジナルSVGです。第三者サイトやInstagramの画像、実在ロゴ、認定マークは使用していません。HTML内にも用途と推奨サイズのコメントを残しています。

| 現在のファイル | 用途 | 実写真への差し替え時の推奨サイズ |
| --- | --- | --- |
| `hero-rural-onsen.svg` | ヒーローの田園・施設外観 | 1600×1100px以上 |
| `water-source.svg` | 汲み上げ直後の透明な源泉 | 800×560px以上 |
| `water-oxidation.svg` | 酸化途中の湯 | 800×560px以上 |
| `water-akayu.svg` | 茶褐色になった浴槽 | 800×560px以上 |
| `yubito-pass.svg` | 湯人手形（現在は検討用イメージ） | 1200×820px以上 |
| `access-rural.svg` | 田園・施設までの道 | 1200×900px以上 |
| `steam-divider.svg` | 装飾用水面ライン | 写真への差し替え不要 |

画像枠には共通の `.image-frame`、用途別の `aspect-ratio` 相当の寸法管理、実写真向けの `object-fit` を適用しています。差し替え後もHTMLの `width` / `height` を実ファイルに合わせて更新してください。

## 実装仕様

- 1ページ完結型。ヘッダー、ヒーロー、赤湯の特徴、沿革、料金、湯人手形、ご利用案内、お知らせ、FAQ、アクセス、フッターを実装
- 生成り・弁柄・藍・稲穂色をCSSカスタムプロパティで管理
- OS配色設定に追従し、ヘッダーの切り替えボタン操作は `localStorage` に保存
- JavaScript無効時はライト配色で主要情報をすべて閲覧可能
- Intersection Observerによる表示演出、湯色のスクロール連動、ヘッダー状態、モバイルメニュー、FAQアコーディオンをVanilla JavaScriptで実装
- `prefers-reduced-motion: reduce` では動きを停止
- 600px以下で「電話・地図・Instagram」の固定CTAを表示。セーフエリア対応
- 料金表は600px以下でカード状表示に変わり、横スクロールを回避
- 提供されたプレゼン用背景・ロゴによる、セッション初回のみの全画面オープニング演出を実装

## 情報・表現上の注記

- 定休日は静的プレビュー指定どおり「火曜日」と表示し、「最新の営業日はInstagramをご確認ください」を併記しています。月曜日も休みかは公開前確認事項です。
- 子供・幼児料金に休日区分を創作していません。
- 過去のお盆特別料金は常設料金として掲載せず、繁忙期に特別料金となる場合がある旨だけを表示しています。
- 湯人手形の仮ビジュアルには「デザイン検討用イメージ」と明記し、未確定の称号名や特典を創作していません。
- 代表挨拶は氏名や本人発言を創作せず、事業承継と今後の方向性を示す仮原稿です。
- 治療・改善効果、未確認の設備、支払方法、駐車場台数等は掲載していません。
- お知らせ3件は日付を持たない明示的な表示サンプルで、実際の営業変更ではありません。
- 参照モックアップURLは共有ページに到達したものの、この実行環境では認証・ブラウザ実行を要するフレーム本体を取得できませんでした。仕様書の詳細なデザイン方針を基準に制作しています。

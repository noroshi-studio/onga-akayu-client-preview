# 遠賀川温泉 おんがの赤湯 — Phase 1 静的プレビュー

デザイン確認用の静的HTML/CSS/JavaScript版です。WordPressテーマではありません。

## 確認方法

### ファイルを直接開く

`index.html` をブラウザへドラッグ＆ドロップするか、ダブルクリックしてください。主要コンテンツとローカルSVGは `file://` でも表示できます。Google Fontsだけはインターネット接続時に読み込まれ、失敗時は日本語システムフォントへ切り替わります。

### ローカルサーバーを使う（推奨）

ターミナルで `static-preview` に移動し、次のいずれかを実行します。

```sh
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080/` を開いてください。

## オープニング演出

- 同一タブのセッション中、初回アクセス時だけ約3.6秒表示します。右上の「SKIP」または `Escape` キーで終了します。
- 開発・確認時はURLの末尾に `?intro=1` を付けると、同一セッション中でも再表示できます。
- `prefers-reduced-motion: reduce` では移動・拡大を行わず、約3.6秒の穏やかなフェードで表示します。JavaScript無効時はオープニングを表示しません。
- 背景は既存のプレゼン用素材、ロゴは施設提供の正式な `Logo_1.png` です。背景とロゴは別要素で表示しています。

### 使用画像

| 種別 | ファイル | 使用箇所・仕様 |
| --- | --- | --- |
| 背景 | `assets/images/opening/onga-akayu-opening-bg.png` | 1920×1280px以上、横3:2前後、PNG・WebP・JPEG。主題は中央付近に配置 |
| 基本ロゴ | `assets/images/logo/Logo_1.png` | オープニング、ヒーロー |
| 文字ロゴ | `assets/images/logo/Logo_2.png` | ヘッダー、フッター |
| シンボル | `assets/images/logo/Logo_3.png` | ファビコン |

同じファイル名で置き換えればHTML・CSS・JavaScriptの変更は不要です。拡張子を変える場合だけ、`index.html` 内のオープニング画像の `src` を変更してください。背景をPC用とスマートフォン用に分ける場合は、同じ箇所の `picture` 内へ `source media="(max-width: 600px)"` を追加できます。画像寸法を変えた場合は、CLS防止のため `width` と `height` も実ファイルに合わせて更新してください。コピーは `index.html` の `.onga-opening__copy` を編集し、不要なら要素ごと削除できます。

## 画像差し替え一覧

ロゴ以外の掲載画像は本案件向けに作成したオリジナルSVGと既存のプレゼン用背景です。第三者サイトやInstagramの画像、認定マークは使用していません。正式ロゴ3点は施設提供の透過PNGを改変せず使用しています。

## 実装仕様

- 1ページ完結型。ヘッダー、ヒーロー、赤湯の特徴、沿革、料金、湯人手形、ご利用案内、お知らせ、FAQ、アクセス、フッターを実装
- 白とブランドカラーのえんじ（`#A02F55`）を中心にCSSカスタムプロパティで管理
- OS配色設定に追従し、ヘッダーの切り替えボタン操作は `localStorage` に保存
- JavaScript無効時はライト配色で主要情報をすべて閲覧可能
- Intersection Observerによる表示演出、湯色のスクロール連動、ヘッダー状態、モバイルメニュー、FAQアコーディオンをVanilla JavaScriptで実装
- `prefers-reduced-motion: reduce` では動きを停止
- 600px以下で「電話・地図・Instagram」の固定CTAを表示。セーフエリア対応
- 料金表は600px以下でカード状表示に変わり、横スクロールを回避
- 既存のプレゼン用背景と正式ロゴによる、セッション初回のみの全画面オープニング演出を実装
- アクセス欄にGoogleマップを直接埋め込み、住所・電話・提供URLへの外部リンクを併設
